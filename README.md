# Carpintería — Tienda web

Aplicación web de comercio electrónico para un negocio de carpintería, desarrollada con React y Vite.

El proyecto permite explorar un catálogo de muebles, consultar los detalles de cada producto, administrar un carrito de compras persistente y realizar pedidos mediante WhatsApp. También incluye un formulario para solicitar cotizaciones de muebles personalizados según las medidas, materiales, presupuesto y necesidades del cliente.

## Características

- Página de inicio responsive.
- Catálogo de productos.
- Vista detallada de cada producto.
- Carrito de compras.
- Modificación de cantidades y eliminación de productos.
- Persistencia del carrito mediante `localStorage`.
- Checkout con datos de contacto y entrega.
- Generación automática del pedido para WhatsApp.
- Formulario de cotización personalizada.
- Carga y vista previa de imágenes de referencia.
- Navegación con React Router.
- Diseño responsive para escritorio, tablet y móvil.
- Página informativa sobre el proyecto y el proceso de trabajo.

## Tecnologías utilizadas

- React
- Vite
- React Router
- React Icons
- JavaScript
- CSS
- LocalStorage

## Estado del proyecto

La primera versión del frontend está terminada y cuenta con un flujo comercial funcional.

Actualmente, los pedidos y las cotizaciones se envían mediante WhatsApp. Como siguiente etapa se planea integrar un backend desarrollado con Spring Boot para guardar productos, clientes, pedidos y cotizaciones en una base de datos PostgreSQL.

## Próximas mejoras

- Integración con Spring Boot.
- Base de datos PostgreSQL.
- Panel de administración.
- Gestión de productos y pedidos.
- Autenticación con JWT.
- Almacenamiento de imágenes.
- Confirmación de pedidos desde el sistema.
- Integración con una pasarela de pagos.

## Objetivo

Crear una experiencia moderna, clara y accesible para mostrar productos de carpintería y facilitar tanto la compra de muebles disponibles como la solicitud de trabajos personalizados.
